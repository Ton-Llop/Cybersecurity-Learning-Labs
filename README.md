# Cybersecurity Learning – Mini Projects

Este repositorio contiene una colección de **pequeños proyectos educativos** desarrollados con el objetivo de aprender **fundamentos de redes, programación en Python y conceptos básicos de ciberseguridad**.

Cada carpeta es independiente y se centra en un tema concreto. Los ejemplos son **simples e introductorios**, pensados para entender cómo funcionan las tecnologías a bajo nivel.


---

## Contenido del repositorio

### 1. Sniffer Learning
Ejercicios básicos para aprender qué es un sniffer y cómo se puede capturar y observar tráfico de red.

- Introducción a la captura de paquetes
- Observación de protocolos comunes
- Comprensión de cómo viajan los datos por la red

---

###  2. Scapy Learning
Ejemplos sencillos usando la librería **Scapy** para analizar y construir paquetes de red.

- Creación y análisis de paquetes
- Exploración de cabeceras
- Primer contacto con manipulación de tráfico a bajo nivel

---

### 3. Sockets Learning
Prácticas para entender cómo funcionan los **sockets** en Python.

- Uso de IP y puertos
- Comunicación cliente-servidor básica
- Diferencias entre TCP y UDP

---

###  4. Keylogger Learning (básico)
Ejercicios muy simples para entender cómo funcionan los **eventos de entrada** (teclado).

- Captura de entradas con fines educativos
- Comprensión de cómo los sistemas gestionan el input
- No orientado a uso real ni malicioso

---

###  5. UDP floods / DoS Concept Learning (básico)
Ejemplos conceptuales para entender **qué es un ataque de denegación de servicio a nivel teórico**.

- Generación de tráfico simple
- Comprensión de por qué estos métodos son poco efectivos en entornos reales
- Enfoque educativo y de análisis, no ofensivo

---

## Objetivo del repositorio

El objetivo principal es:
- Aprender conceptos básicos de redes
- Entender cómo funcionan herramientas de bajo nivel
- Construir una base para estudios posteriores en ciberseguridad defensiva

Este repositorio **no pretende ser una colección de herramientas de ataque**, sino un espacio de aprendizaje y experimentación.

---

## Nota ética

Todos los scripts deben usarse **únicamente en entornos de prueba**, con equipos propios o con autorización explícita, ya que son tan básicos que ni funcionarían en la vida real.
